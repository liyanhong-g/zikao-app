# 考证刷题助手 ZikaoApp

一个本地离线的考证刷题小工具：选择题自动判题、对错即时标色、
错题自动归集、一键导出，数据全部存在你电脑上，不上传任何地方。

---

## ✅ 环境要求

**不用装任何东西。** 直接用下面 `发布包` 里的 `ZikaoApp.exe` 双击即可。
（已内置 .NET 运行环境，Win10 / Win11 64 位均可）

发布包：https://github.com/liyanhong-g/zikao-app/releases/tag/v1.0.0

---

## 🚀 第一次使用

1. 把 `ZikaoApp` 文件夹解压到任意位置（桌面、D 盘都行）
2. **双击 `ZikaoApp.exe`**
3. 程序会在同目录自动生成 `zikao.db`（题库数据库），无需手动建
4. 点右上角 **「导入」**，选择你的题目 JSON 文件，等提示「导入完成」即可开刷

> 💡 首次启动没有题目是正常的，导入后自动刷新。

## 📥 题目 JSON 格式（导入模板）具体可参考（题目导入模板.json）文件
### 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| `Type` | ✅ | `Choice` 选择题 / `ShortAnswer` 简答 / `Essay` 论述 |
| `Text` | ✅ | 题干 |
| `OptionsJson` | 选择题必填 | 字符串数组。**已带 A. B. 前缀就写全**，程序会自动识别不再叠加 |
| `Answer` | 选择题必填 | 正确答案**下标**，从 `0` 开始（0=A，1=B，2=C，3=D） |
| `AnswerText` | 可选 | 参考答案，显示在「查看解析」里 |
| `Analysis` | 可选 | 解析文字 |
| `SubjectCode` | 可选 | 科目，用于筛选（如 政治 / 高数 / 英语） |
| `ExamTime` | 可选 | 场次或年份，用于筛选（如 2025真题） |
| `Code` / `Remark` | 可选 | 题号、备注 |

> ⚠️ 同一「科目 + 场次 + 题干」视为同一道题，**重复导入会更新答案和解析，不会重复加题**，错题标记也会保留。

## 🎮 功能用法

| 操作 | 说明 |
|---|---|
| 点选项 | 选择题立即判题：✅ 绿色为对，❌ 红色为错，正确项自动标绿 |
| 改选 | 先错后改对，错题标记会自动取消 |
| 简答 / 论述 | 点「❌ 标记为错题」手动收录 |
| 📝 查看解析 | 展开看参考答案与解析 |
| 搜索 / 科目 / 题型 | 顶部实时筛选 |
| 错题模式 | 只刷错题，配合「清除错题标记」「导出错题」复习 |
| 随机刷题 | 打乱顺序模考 |

## 📦 数据在哪？

题库文件就在 exe 旁边：

ZikaoApp/

├─ ZikaoApp.exe ← 主程序

├─ zikao.db ← 你的题库 + 错题记录（可备份这个文件）

└─ crash.log ← 出问题时自动生成，发给作者排查

---
**换电脑 / 备份**：把 `zikao.db` 拷走，放到新电脑的同目录即可继续使用。

## ❓ 常见问题

**双击没反应 / 闪退？**
→ 看 exe 旁边有没有 `crash.log`，把里面内容发给作者；一般是杀软拦截或解压不完整，重新解压并以管理员身份运行试试。

**导入成功但列表空的？**
→ 检查 JSON 里 `Type` 拼写是否为 `Choice` / `ShortAnswer` / `Essay`，以及 `OptionsJson` 是不是合法数组。

**改了答案再导入，错题标记没了？**
→ 不会丢。程序按「科目+场次+题干」匹配更新，只刷新题目内容，`IsWrong` 保持不变。

**装到 Program Files 后提示没权限？**
→ 建议直接放桌面或 D 盘解压用（绿色版），不要放进系统目录。
